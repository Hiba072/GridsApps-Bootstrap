
# NexaTech Solutions — Bootstrap Training Project

## Training Information

- Company: Grids Apps
- Program: Full Stack Web Development Internship
- Track: Foundation
- Days Completed: Day 06 & Day 07
- Framework: Bootstrap 5.3.x

## Project Overview

NexaTech Solutions is a responsive software company website developed as part of the Grids Apps Full Stack Web Development Internship.

The project demonstrates Bootstrap's responsive grid system, utility classes, reusable components, interactive elements, and custom styling.

## Day 06 — Bootstrap Setup, Grid & Utilities

### Day Objective

Build responsive sections rapidly using Bootstrap 5.3.x.

### Completed Exercises

#### 1. Hero and Responsive Card Grid

- Created a hero section for NexaTech Solutions.
- Built responsive service cards.
- Used Bootstrap containers, rows, and columns.
- Applied spacing, flex, and display utilities.
- Implemented responsive breakpoints.

#### 2. Challenge B01 — Responsive Pricing

- Created three pricing plans: Starter, Professional, and Enterprise.
- Used Bootstrap Grid and Cards.
- Highlighted the Professional plan.
- Implemented responsive layouts for mobile, tablet, and desktop.

#### 3. Challenge B03 — Dashboard Summary

- Created a responsive dashboard layout.
- Added sidebar and top navigation.
- Built four KPI cards.
- Created a responsive project data table.
- Added status badges.

## Day 07 — Bootstrap Components, Forms & Interaction

### Day Objective

Use Bootstrap components and JavaScript plugins while maintaining a consistent custom brand.

### Completed Exercises

#### 1. Challenge B05 — Offcanvas Navigation

- Created an interactive offcanvas navigation menu.
- Added a menu toggle button.
- Implemented open and close functionality.
- Added navigation links between project pages.
- Used Bootstrap JavaScript components.

#### 2. Challenge B06 — Modal Form

- Created an interactive modal contact form.
- Added fields for full name, email, service, and message.
- Used Bootstrap form controls and validation feedback.
- Implemented required-field validation.
- Added a confirmation message for valid demo submissions.
- Added modal open and close functionality.
- No backend submission is implemented.

#### 3. Challenge B07 — Accordion FAQ

- Created an interactive FAQ accordion.
- Added realistic questions about NexaTech services.
- Implemented expandable and collapsible answers.
- Used Bootstrap accordion components.
- Included keyboard-accessible controls.
